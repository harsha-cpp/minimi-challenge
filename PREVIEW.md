# preview branch

This branch contains the working app with the new interface and optional research clarifications. Retired archive ingestion, corpus experiments and their CLI/test entry points stay on rough. The one eligibility helper remains for existing evidence contracts; active chat uses live Exa era research.

Run `npm ci`, configure `.env` using `.env.example`, and run `npm run dev`. For the existing isolated local preview use http://localhost:3001. Runtime databases and API credentials are never committed.

The 25 development commits use the approved 13–14 November 2026 IST metadata dates. Branch preparation commits use their actual creation time. Review preview before publishing main; master remains the existing remote default.
